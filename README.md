# Number Guessing Game

## Project Overview
The Number Guessing Game is a console-based Java application
where users try to guess a randomly generated number.

The game provides hints to help users identify the correct number
within a limited number of attempts.

## Objective
To develop an interactive console game using core Java concepts
such as random number generation, user input, loops, and conditional
statements.

## Technologies Used
- Java
- IntelliJ IDEA
- java.util.Random
- java.util.Scanner

## Features
- Random number generation
- Easy, Medium, and Hard difficulty levels
- Too High and Too Low hints
- Attempt counter
- Maximum attempt limit
- Win and lose messages
- Play Again option
- Multiple-round tracking
- Round summaries
- Input range validation

## Difficulty Levels

| Level | Number Range | Maximum Attempts |
|---|---|---|
| Easy | 1–50 | 10 |
| Medium | 1–100 | 7 |
| Hard | 1–200 | 5 |

## How to Run
1. Install a Java Development Kit (JDK).
2. Open the project in IntelliJ IDEA.
3. Open src/Main.java.
4. Run the Main class.
5. Select a difficulty level.
6. Enter guesses according to the prompts.

## Learning Outcomes
- Understanding Java classes and methods
- Using Random and Scanner
- Applying if-else statements
- Implementing while and do-while loops
- Managing attempts and round statistics
